## 🔴 发现一个会崩的输入（P1，未修）

`MarkdownParser.swift:265` `tableAlignment` 里 `removeFirst` / `removeLast` 的**顺序陷阱**：

```swift
let leadingColon = trimmed.hasPrefix(":")
let trailingColon = trimmed.hasSuffix(":")
var core = trimmed
if leadingColon { core.removeFirst() }
if trailingColon { core.removeLast() }   // ← 当 trimmed == ":" 时，core 已是空串 ⇒ trap
```

⚠️ 单个 `":"` 上 `hasPrefix` 与 `hasSuffix` **同时为真** ⇒ 先删首字符、再 `removeLast` 空串 ⇒
`Fatal error: Can't remove last element from an empty collection`。已在 `/tmp` 实测复现。

**最小触发输入（README 内容可控 ⇒ 远程内容让 App 崩）**：

```
| a |
| : |
```

（`isTableHeader` 里表头 1 格、分隔行 1 格 ⇒ 计数相等 ⇒ 走到 `tableAlignments([":"])` ⇒ 崩。
`|:|`、`| : |` 同样命中。）

   与 §6.7 那条"HTML 降级**不丢内容**"的既有原则冲突（旧行为"每格一段"正是为了不丢）。

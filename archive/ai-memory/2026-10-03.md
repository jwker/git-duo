## GitDuo 真机登录按钮灰色卡死修复
- 现象：真机上"使用 GitHub 登录"按钮灰色不可点；模拟器正常。
- 根因：`AuthStore.startWebSession()` 忽略 `ASWebAuthenticationSession.start()` 返回值；start 失败时 completion 永不回调，状态卡在 `.authenticating`（按钮唯一禁用条件，LoginView.swift:70）。iOS 挂起而非杀进程，卡死状态跨"重新打开"持续。另外 `PresentationAnchorProvider` 找不到 key window 时返回空 `ASPresentationAnchor()`，是真机 start 失败的典型诱因。
- 修复（`GitDuo/Features/Auth/AuthStore.swift`）：
  1. `guard session.start() else { state = .signedOut; return }`
  2. 展示锚点改为渐进兜底：foregroundActive 场景的 key window → 任意窗口 → 空窗口。
- 验证：`swiftc -parse` 通过；xcodebuild 在本环境因包解析沙箱受限无法跑（环境问题，非代码问题）。

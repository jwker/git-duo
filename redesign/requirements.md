## 1. 产品定位

**通用 GitHub 移动客户端**——专注做好 iPhone 单手高频场景（看仓库、审 PR、处理 Issue 和通知）。本期**只做普通 iPhone 版本，不考虑折叠屏（iPhone Duo）适配**，架构上不做任何 Duo 预留。

**目标用户**：日常参与 GitHub 协作的开发者（个人项目 + 团队仓库）。

**设计原则**：
1. 单手可达：核心操作都在拇指区，Tab + 推入栈，杜绝反直觉的手动 selection 导航
2. 内容优先：正文（README / diff / 评论）占最大面积，装饰性元素最小化
3. 快：ETag 缓存、图片降采样、解析结果缓存——性能是一等需求
4. 真实感：完整的空态 / 加载态 / 错误态，任何失败都有出口（重试 / 提示 / 重新登录）

## 2.1 仓库 Tab 功能细节（已评审 2026-10-03）

**前提**：移动端无 git 工作副本，文件编辑 = GitHub 网页式编辑（API 直写，每次保存即一次 commit）。做不到：pull / rebase / stash / 本地未提交 diff。

**文件操作（主功能）**：

| 操作 | 决策 |
|---|---|
| 编辑文件 | 查看器 →「编辑」→ 语法高亮轻量编辑器（Swift/JS/Python/MD 等常见语言关键字着色 + 行号，自研轻量实现）→ 提交面板 |
| 新建文件 | 输入路径（自动建目录）+ 内容，contents API `PUT` |
| 上传文件 | 来源：**文件 App（document picker）+ 相册图片**；≤1MB 走 contents API，大文件走 Git Data API（blob→tree→commit→ref，上限 100MB） |
| 删除/重命名 | 文件菜单，`DELETE` / `PUT` |
| 多文件暂存 | 本地暂存队列，攒一批改动一次 commit（Git Data API 单次 tree+commit） |
| 冲突处理 | 提交 409 时提示"远端已更新"，可选查看最新版或强制覆盖 |

**提交策略**：提交面板**每次可选**——直接提交到当前分支（默认），或提交到新分支并一键开 PR（复用 PR diff 组件）。

**Git 操作（进阶全套）**：分支列表/创建/切换/删除；Commits 历史按分支浏览 + 单条 diff 详情 + Revert（反向提交）；分支合并 merge（冲突引导去网页）；详情页顶部分支切换器联动代码与 Commits 分区。

## 3. 信息架构

```
TabBar（4 个，原 5 个）
├── 首页        Feed + 进行中聚合 + 快捷入口
├── 仓库        我的仓库(分段) → 仓库详情(代码/Issues/PR/Commits)
├── 探索        搜索 + Trending
├── ~~收件箱      通知列表（Tab 角标显示未读数）~~ ← 本期不做
└── 我的        Profile / 热力图 / Star / 设置

推入栈示例：
仓库 Tab → 仓库详情 →(代码) 文件树 → 文件内容
                    →(Issues) Issue 列表 → Issue 详情 → 新建评论
                    →(PR) PR 列表 → PR 详情(对话|Commits|Files) → Diff 全屏
~~收件箱 → 通知点击 → 直接推入对应 Issue/PR 详情~~ ← 通知本期不做
```

**与 1.0 的关键差异**：
1. 仓库详情从"只有 README"升级为四分区枢纽（代码/Issues/PR/Commits），一切从仓库出发
2. 列表点击 = 标准 `NavigationLink` push（1.0 的手动 selection 坑从架构上消灭）
3. 动态从独立 Tab 收进首页聚合；新增探索 Tab 承接搜索/Trending
4. PR diff 以单栏上下对比呈现，文件卡片可折叠

## 4. 关键交互定义

| 场景 | 行为 |
|---|---|
| 登录 | 授权页 → 成功后直接进首页；失败按钮立即恢复可点 + 错误横幅 |
| 通知已读 | 点进详情即标已读；列表项实时移出未读段；缓存主动失效 |
| 发评论 | 发送中按钮转圈；失败 → 输入框上方红色横幅（可关闭），草稿保留 |
| Star | 详情页大按钮即时切换 + 数字动画；Star 管理页可取消 |
| Token 过期 | 任意页面 401 → 静默登出 → 登录页带"会话过期"提示 |
| PR Diff | 文件卡片折叠/展开；行内 +/- 绿红底；长按行可复制 |
| 空态 | 每个列表有插画式空态；错误态带重试按钮 |
